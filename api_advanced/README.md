
# API Advanced

This project focuses on using the Reddit API with Python's Requests module.

## Tasks

### 0. How many subs?

`0-subs.py`

Queries the Reddit API and returns the total number of subscribers for a given subreddit. Returns 0 if the subreddit is invalid.

### 1. Top Ten

`1-top_ten.py`

Queries the Reddit API and prints the titles of the first 10 hot posts for a given subreddit.

### 2. Recurse it!

`2-recurse.py`

Uses recursion and Reddit API pagination to retrieve the titles of all hot posts in a subreddit.

### 3. Count it!

`3-count.py`

Uses recursion to retrieve hot post titles, counts the occurrences of specified keywords, and prints the results in descending order of frequency.
